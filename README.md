## General Submission Rules Followed
- Each lab maintains its own isolated directory (`lab-01` to `lab-10`) with a dedicated `README.md` and `screenshots/`.
- Dependency folders (`node_modules`) and secret environment files (`.env`) are strictly excluded via `.gitignore`.
- Every route and API endpoint returns standard HTTP status codes.
- Sensitive credentials and passwords are never stored in plain text.
