Place your Postman screenshots in this folder.

Naming convention:
  01-get-all-books.png    – GET /books
  02-get-single-book.png  – GET /books/:bookId (success)
  03-post-book.png        – POST /books
  04-put-book.png         – PUT /books/:bookId
  05-delete-book.png      – DELETE /books/:bookId
  06-get-404.png          – GET /books/:bookId (not found)

After adding the screenshots, run:
  git add screenshots/
  git commit -m "docs(lab-02): add Postman screenshots"
  git push
